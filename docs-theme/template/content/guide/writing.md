# Writing

## Extensions

The build enables the same Markdown extensions as the Zensical site:
`admonition`, `attr_list`, `md_in_html`, `tables`, `toc` with permalinks,
`pymdownx.highlight`, and `pymdownx.superfences` with a `mermaid` fence.
`pymdownx.details` is added for collapsible blocks.

## Attributes

Add a class with `attr_list`: `Text{ .class }`.

!!! info
    Classes the theme does not style are left as they are.
